# 🏎️ Holley EFI Python Tuning Tools

Free, lightweight Python tools designed to speed up tuning and data analysis for Holley EFI (Terminator X, HP, Dominator, and Sniper).

## 🚀 Features
- **Instant Fuel Map Comparison:** Compare any Base Map to a Dyno/Learned tune directly from your clipboard with a single click.
- **Visual Delta Heatmaps:** Color-coded heatmaps showing exactly where fuel was added (Red / Lean) or pulled (Blue / Rich).
- **Supports Large Tables:** Fully compatible with Holley standard (16x16) and large (31x31) fuel tables.
